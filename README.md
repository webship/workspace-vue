# @webship.co/workspace-vue

Vue for the [Webship Workspace](https://github.com/webship/workspace) dashboard: a builder that makes a Nuxt app with
the official starter and serves it from a container of its own (the app's Node.js in the app's container), the Vue step
pack wired into the workspace's testing setup of that app, and its AI items. The workspace is container-based (DDEV by
default).

The builder, the tests and CI come with the first release, `1.0.0`.
